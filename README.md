# Exercícios de C – Curso e Faculdade

Este repositório contém meus **exercícios de programação em C**, feitos durante o meu curso de Técnico Especialista em Programação de Sistemas Informáticos e nas aulas da faculdade de Engenharia de Software. O objetivo é **praticar e fixar conceitos** de programação, incluindo **estruturas condicionais, loops, vetores, matrizes e funções**.

## Estrutura do repositório

- `Exercicio 01/` – Primeiro exercício  
- `Exercicio 02/` – Segundo exercício  
- `Exercicio 03/` – Terceiro exercício  
- ...  
*(cada pasta contém o arquivo `.c` correspondente)*

## Tecnologias

- Linguagem: C  
- Compilador sugerido: GCC

## Como executar os exercícios

1. Abra o terminal e navegue até a pasta do exercício que você quer executar.  
2. Compile o arquivo `.c` com o comando:  
```bash
gcc main.c -o main
```
3. Se não conter nenhum erro no seu código (no meu não tem rsrs) você já pode executar desta forma.
4. Digite no terminal:
```bash   
./main
```
